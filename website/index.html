常见问题

你想知道的。

支持哪些 Agent？
Codex、Claude Code、OpenCode、Grok、ZCode、DeepSeek 开箱即用；任何兼容 ACP 协议的 agent 都能作为自定义项接入。每个会话绑定它的 agent，互不干扰。
会取代我的终端吗？
不会。Marionette 不实现 agent runtime，只负责启动、展示、切换与记录。Agent 的能力与行为全部来自你已安装的 CLI 本体——终端该怎么用还怎么用。
我的 Key 和数据存在哪里？
全部在本机。凭据落在本地凭据库，对话与记录是本地文件，不经任何云端中转；卸载即清。
支持哪些系统？
Windows 10 / 11（x64）。提供免安装的便携版，解压即用。
已经在用这些 CLI 了，为什么还需要它？
单个 Agent 的会话，终端足够。多个 Agent 并行时，切换、对比、记录的成本都在你手上。Marionette 把这些搬进同一个窗口，并让它们共享同一批模型与记忆。
