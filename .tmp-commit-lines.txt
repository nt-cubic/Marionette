feat: land the parallel worklines — session pin/order, effort reject latch, notify cadence

Three features that lived in the working tree alongside the cross-agent
bridge rounds, co-verified with them (248 Rust tests + tsc/vite green on
this exact tree; the shipped Marionette-Engine.exe includes them):

- Session pin & ordering (shelf): pin buttons on project/session rows
  with an always-visible pinned mark, pinned rows float to the top with
  recency preserved underneath, done-but-unread dialogs auto-expand
  their collapsed project, and a new verify script
  (scripts/verify-session-order.mts) pins the ordering rules down.
- Effort reject latch (acp + composer): grok ≥1.0.5x answers -32602
  "the session's current model does not support reasoning effort" for
  GLM-family catalog entries even when tiers are declared. The error is
  now latched per model (CapabilitySnapshot.effortRejectModels): the
  Composer drops the Effort control for that model and update_session
  answers further effort writes locally as no-ops; session-local, so a
  grok update self-heals the knob.
- Notify cadence: completion and silent-stop chimes also play while the
  window is focused (the user may be in another dialog), and lastActivity
  state publishes are throttled to 1 Hz so a hot event stream no longer
  re-renders the App root per chunk.
