# Marionette v0.8.5：自研引擎转正、引擎形态可切换、Antigravity 登录按钮

单文件便携版。下载双击即用，需要 WebView2 Runtime（Win11 与更新过的 Win10 自带）。

## 自研 Rust 引擎转正（默认形态）

- 模型共享引擎从「外部 magpie 进程」换成本进程内的 Rust 实现：**exe 从 24.6 MB 降到 6.2 MB**，不再下载/落位第二个引擎进程，任务管理器里也没有独立引擎进程了。
- 引擎随应用升级；`~/.marionette/engine/data/` 继续保存兼容 Magpie 格式的 `providers.json`、登录桥缓存与用量账本，**从旧版升级无需迁移**。
- 引擎仍是懒启动：存在跨用模型绑定或跨用入口才拉起；30 分钟无绑定且无需求自动休眠。
- 模型目录、订阅额度、key 余额、跨用路由（claude / codex / grok / opencode / dsh / pi / zcode）全部照旧。

## 引擎形态切换（逃生口）

- 模型共享面板新增「引擎形态」：默认**内置 Rust**，遇到问题可一键切到 **magpie** 子进程形态（与旧版行为一致），随时切回；切换会重启网关。
- 切到 magpie 后用面板的「检查更新」从 GitHub 下载安装 magpie；在下载之前引擎保持未运行，面板会明确提示——不会偷偷用另一个引擎顶包。
- 偏好保存在 `~/.marionette/engine-preference.json`，重启后保持。

## Antigravity 登录按钮（issue #14）

- 修复：选择 Antigravity 时没有登录按钮。现在未登录时会显示登录横幅与 **Sign in** 按钮；点击后自动发起 Google 浏览器授权（免费额度，每 5 小时重置），完成后状态自动刷新。
- 登录凭据与新建会话自动触发的授权共用同一份（`~/.gemini/antigravity-acp/acp_token.json`），登录探测消息改为随界面语言显示。

## 其它

- 合并引擎线全部累积改进：引擎网关协议翻译、流式工具调用、订阅登录桥、上下文窗口、用量台账等（详见引擎分支历史）。
- 内置 magpie 回退种子继续随构建提供（仅 `MARIONETTE_ENGINE=magpie` 构建 SKU 使用）。
- 回归：Rust 全量 1241 项、前端构建与双语文案检查通过；含 Antigravity 登录驱动真机 oracle。

## 安装

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.7.x / 0.8.x 升级无需迁移，数据目录与配置不变。
