# Marionette v0.8.6

## 浏览器体验

- 修复浏览器网页遮挡图片预览、权限确认和其他应用弹窗的问题。
- 拾取元素和框选区域入口常驻显示，修复按钮文字被挤压的问题。
- 自动打开网页时保留浏览器所在的分屏位置。
- 对话中的网页链接默认在内置浏览器打开，右键可选择系统浏览器。

## 更新

- 检查更新时可直接阅读版本更新说明。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```
