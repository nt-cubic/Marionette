# Marionette v0.8.4

## 内置模型共享引擎转正

- 默认使用进程内 Rust 引擎，不再启动 Magpie 子进程；应用退出时网关线程随之结束。
- 共享模型目录、Chat / Responses / Anthropic Messages、流式、工具调用、订阅额度和错误透传继续沿用现有合同面。
- `MARIONETTE_ENGINE=magpie` 保留一个发布周期的回退构建，便于真实长回合和新 Agent 组合对照。

## 数据与设置可靠性

- 损坏、权限错误、BOM、运行中消失或外部并发修改的 `providers.json` 一律禁止覆盖；保存前保留 `providers.json.bak`，Windows 使用原子替换。
- 配置无法读取时模型共享接口返回明确错误，不再把全部来源显示成“已删除”。
- 修改代理后停止/重启引擎即可生效，不再被首次启动值锁死。
- Rust 引擎账本改为独立的 `engine-usage.jsonl`；旧 Magpie `usage.jsonl` 保持不动。

## 订阅跨用

- Claude 订阅桥支持 base64 和 URL 图片，工具结果里的图片也会转发。
- Codex 继续保留大请求压缩、断流续答与可选 WebSocket 路径。
- Grok、Codex、Claude 登录失效和额度耗尽继续给出可行动的来源级错误。

## 验证

- Rust 全量测试：1223 passed / 0 failed / 5 ignored。
- 引擎合同：C1–C6、D1–D10 全绿。
- 默认 Rust 与 Magpie 回退路径均通过编译检查；前端生产构建通过。
- 默认便携版构建使用 `engine-rust`，不导入或内嵌 Magpie 载荷。
