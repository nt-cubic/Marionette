# Marionette v0.8.4：Google Antigravity 上线、工作区统一分屏

单文件便携版，内置跨用引擎。下载双击即用，需要 WebView2 Runtime（Win11 与更新过的 Win10 自带）。

## Google Antigravity（新 Agent）

Google 官方 `agy_acp_server` 作为内置 Agent 加入——用 Google 账号登录即有**免费额度**（每 5 小时窗口重置），不需要任何 API key。

- **一键安装**：Agent 菜单选 Google Antigravity → 安装，自动从 dl.google.com 下载官方 zip（约 105 MB），校验 SHA-256 与文件成对完整性后落位；也支持手动下载后把整个解压目录加入 PATH。
- **登录即用**：新建对话会自动弹出 Google 登录页面；浏览器没有弹出时，对话里会出现带授权链接的提示卡兜底。
- **模型与档位**：免费档默认 `gemini-3.8-flash`；思考档（low / medium / high）与会话模式（default / auto_edit / yolo）都在 composer 里直接切。
- **用量与历史**：Token 用量分析会把 `~/.gemini/antigravity-acp` 的历史会话回填进面板（输入 / 输出 / 缓存 / 思考四桶，模型归属到 `gemini-3.x-*`）；历史会话可导入。
- **磁盘卫生**：Windows 版服务端每次启动会往系统临时目录解压约 100 MB——Marionette 为每个会话重定向临时目录并在结束时回收，Agent 菜单的版本探测也不会再触发解压；另有存量泄漏清理命令与诊断报告摘要。

## 工作区统一：文档 / 浏览器 / 收纳盒进分屏树

- 文档标签页、内置浏览器、收纳盒不再是独立布局——它们成为与会话标签**同一棵分屏树里的窗格标签**，可拖拽分屏、上下分、跨窗格移动。
- 收纳盒与文档标签可**撕出独立小窗**，随时合并回主窗；浏览器受实现限制留在主窗。
- Ctrl+W / Ctrl+Tab / Ctrl+1..9 统一操作聚焦窗格的标签序列（会话与工作区标签混排）。
- 冷启动恢复只恢复文档与收纳盒标签；浏览器标签不进恢复，避免异常页面形成恢复循环。

## 收纳盒强化

- 新增**置顶**、**编辑**（文字 / 链接）、**标签**（筛选、多色归类）。
- 所有卡片可**拖入输入框**当附件 / 引用；输入框草稿可**一键存盒**（存副本，不清空输入）。

## Composer 与对话流

- **粘贴文件即附件**：在资源管理器复制的文件，直接在输入框粘贴就会按真实路径挂上附件。
- **单美元行内公式**：`$x^2$`、`$E=mc^2$` 渲染成公式；货币（`$5 to $10`）、shell 变量（`$HOME`）保持字面，不再互相误伤。
- **后台面板命令退出码人话**：`grep` 退出 1 显示「无匹配」、127 显示「命令不存在」、`128+n` 显示信号名。

## 修复

- DSH 用量回填：会话目录内 v3 / v4 共存时取最高代，不再双计；将来 v5 不漏读。
- 右栏改动文件列表：中文文件名不再显示成八进制转义（git porcelain 关 quotePath + rename 解引号）。
- 会话失败卡补盖 agent 归属——切换 Agent 后不再把旧失败算到当前会话头上。
- 内置浏览器：CDP 等待全部有界，丢帧的 ACP 投递可恢复，不再偶发卡死。

## 引擎与其它

- 内置 magpie 种子更新到 **v0.1.4514**（上游累积约 108 版；发布时拉取的 latest stable）。
- 新增 Antigravity 回归 15 项与真库 / 真网 oracle；Rust 全量 681 项、前端构建与双语文案检查通过。

## 安装

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.7.x / 0.8.x 升级无需迁移，数据目录与配置不变。
