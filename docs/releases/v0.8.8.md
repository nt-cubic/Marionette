# Marionette v0.8.8

## Agent 与输入

- 修复 Grok 会话冷启动恢复后「始终批准」显示已开启、但权限仍会继续询问的问题；保存的批准策略现在会真正回放到 Agent。

## 窗口与通知

- 修复 Windows 最小化再恢复后，任务栏黄色/红色进度条和标题提醒可能一直残留的问题；回到窗口后会可靠清除。

## 图片

- 点击对话中的图片现在会直接打开与右栏图片入口相同的全屏查看器，不再只在回复卡片内放大。

## 额度

- 修复 Antigravity 会话点击额度刷新或完成回合后没有请求 `/usage` 的问题。
- 现在会正常显示 Gemini、Claude/GPT 等额度组，以及已用比例、剩余比例和重置时间。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.8.x 升级无需迁移用户数据。
