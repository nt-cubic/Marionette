# Marionette v0.7.10：右栏三标签与图片中心

单文件便携版，内置跨用引擎。下载双击即用，需要 WebView2 Runtime（Win11 与更新过的 Win10 自带）。

## 右栏拆成三个固定标签

- **当前**：保留任务、额度、改动文件和后台任务，不必再跨图片区或共享配置找当前对话的数据。
- **共享**：集中收纳 MCP、技能、插件、记忆和交接设置。Ctrl K 打开插件时会直接切到这里。
- **图片**：单独展示当前对话里出现过的图片，长列表只在本页内部滚动，不再把额度、任务等卡片往下顶。
- 标签选择会记住；也支持用左右方向键切换。

## 对话图片集中查看

- 汇总你附上的图片，以及 agent 从工具、浏览器或桌面截图里实际看到的图片；同一张图自动去重。
- 图片按日期分组，可按「全部 / 你的 / 工具」筛选；右栏压到 220px 时仍保持清晰的两列网格。
- 大图查看器支持前后翻页、缩略条、回到对话原卡、在文件夹中显示和复制路径。
- 点图片外的空白、遮罩、Esc 或右上角关闭键都能退出查看器。
- 图片能力按「支持 / 不支持 / 未知」三态判断，只有明确不支持时才变灰，不再把缺元数据的模型误判成不能看图。

## 修复

- 旧转录中的附件没有 `marks` 字段时，不再导致 You 卡或图片页崩溃。
- 修正右栏窄宽度下的标签、筛选和图片网格排版。
- opencode 视觉模型条目现在同时写入 `attachment` 和 `modalities.input`，修复「界面允许附图，但模型读图时仍报不支持图片输入」的问题。

## 安装

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。

- 文件：`Marionette.exe`
- 体积：20.55 MB
- SHA-256：`89763ED93AE10F318FA338D9F9F716F5FD29F02D7802E16B3FC08E640FF07792`

从 0.7.8 升级无需迁移，数据目录与配置不变。
