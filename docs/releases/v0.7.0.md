v0.7.0：界面 v2——整套视觉语言重做（对话流、左右栏、输入框、弹窗、模型共享、圆桌、收纳盒、贴边、用量），新增「改动」标签页与发送键旁的会话信息圆圈；另含共通插件层与几处修复。

单文件便携版，内置跨用引擎。下载双击即用，需要 WebView2 Runtime（Win11 与更新过的 Win10 自带）。

## 界面 v2

规范见 `docs/ui-language.md`（v2），设计稿在 `docs/design/ui-v2/`。保持横平竖直与卡片流的个性，整体更克制、层级更清楚。

- **对话流**
  - 卡片改成左直右圆：左上 / 左下直角，右侧 3px 圆角。左边 3px 身份条成为一根直线：You 是绿色，回复是 agent 的墨色，过程卡是灰色。
  - 回复卡头只写 agent 名，和 You 用同一种标签样式。卡底是「这一条怎么跑的」：模式 · 模型 · 档位，细竖线后是耗时与 token。
  - 「过程卡」指 You 与回复之间的思考 / 工具调用块，现在边框更实、底色更轻，箭头改成画线。运行中的描边和流光跟随 agent 色。
  - 消息目录（右上角竖条）保留绿色圆点，两行预览不再被裁。
- **agent 身份色**：每个 agent 一种低饱和「墨色」，只用在卡片左条、运行中的描边和当前进度条上，名字本身不上色。
- **左栏**
  - 搜索、状态过滤、分组标题全部贴面，没有独立的框。
  - 聊天列表与收纳盒 / 圆桌同一缩进、同一行高。
  - 未运行的对话变灰，选中项是绿色左条加浅绿底。
  - 底栏去掉漂移的小点，改成图标本身变色。
  - 去掉左下角的折叠按钮。
- **右栏**：按「任务 → 额度 → 改动文件 → 共享」重排。
  - 额度高亮的是「这一轮由谁计费」：自家订阅，或经模型共享借来的来源。重置时间统一写成「11/7 21:09 重置」。
  - 「跨 agent 共享」改名「共享」，带 MCP / 技能 / 插件 / 记忆的分类摘要，子块统一成行。
  - 去掉右下角的折叠按钮和底部的统计行，这些数据移到了信息圆圈里。
- **输入框**
  - 发送键左边新增会话信息圆圈：圆环按 agent 色画出上下文占用。点开是浮层，显示上下文条、解码 / 预填充速度、首字延迟、改动、轮次、缓存命中，以及 token 明细。
  - 模式芯片改为带底色的芯片；聚焦时上沿显示主题绿。
  - 右上角有展开按钮。
- **「改动」标签页**：在右栏或交付卡里点文件，标签行会出现「改动 N」，左列是改动文件（M/A/D 与增删行数），右侧是相对 HEAD 的 diff。它与收纳盒、圆桌、用量等整页互斥，Ctrl+W 或 × 关闭；窄宽度下按钮只留图标。贴边和撕出的窗口仍然使用弹窗。
- **模型共享**：改成「来源 | 模型」两栏。左栏每个来源显示已共享数和剩余额度（最紧的窗口 / 余额 / 已满）。右栏是整源开关、借给哪些 agent、额度块、过滤芯片和模型表。
- **弹窗与动效**：所有弹窗统一外观，顶边有一条 2px 主题绿线，关闭时淡出。打开「减少动效」时关闭不会卡住。
- **标签页**：当前标签顶边有一条 2px 主题绿线。
- 圆桌、收纳盒、贴边窄条、用量分析、文档 / 浏览器标签页同步改成 v2 外观。

## Added

- **共通插件层**：安装一次 MCP 插件，所有 agent 都能用。插件统一挂在本机 localhost 网关 `/mcp/p/<id>` 上，不改写任何 agent 自己的配置。stdio 插件按会话按需启动，http 插件直接中继。登记处在 `~/.marionette/plugins/`，另有一个全局 skills 目录。

## Fixed

- **本轮 token 统计**：本轮数字不再混进会话累计（Grok 的 `_meta.usage` 是整段对话的总账）；TPS 只按生成时间计算，不再算进工具等待时间。
- **长内容弹窗**：权限提示里塞进整条命令或整个文件时，弹窗不再超出屏幕，「允许 / 拒绝」按钮始终点得到。所有共用弹窗外壳都按同样方式修了。
- **贴边窄条**：⋯ 菜单和 Add project 弹出的东西不再被整页覆盖层挡住。
