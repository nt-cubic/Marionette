# Marionette v0.8.10

## 窗口与通知

- 任务栏黄色/红色进度条与标题提醒，现在以系统前台窗口为准判断你是否在窗口里。最小化、切到别的程序再回来，条会在回到窗口后 1–3 秒内自动清除，不再长期残留。
- 窗口在前台时回合完成不再误亮黄条；只有真正在别的窗口时才会抬起提醒。
- 新增通知生命周期日志（`[notify] attention raised/cleared`，带事件类型与窗口），排查残留时有据可查。

0.8.9 只做过一次内部构建、未单独发布，它的修复已包含在本版中。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.8.x 升级无需迁移用户数据。
