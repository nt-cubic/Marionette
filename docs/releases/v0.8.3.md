# Marionette v0.8.3：助手优先的员工体验、诊断报告与浏览器修复

单文件便携版，内置跨用引擎。下载双击即用，需要 WebView2 Runtime（Win11 与更新过的 Win10 自带）。

## 员工与助手

- 首次使用会自动准备一位可以直接聊天的示例助手 **Mari**，默认绑定第一个已启用 Agent 和该 Agent 的默认模型，不需要先填写人格、预算或项目策略。
- 示例助手只创建一次；用户主动移除后不会在重启时自动复活。点击前不会发送 bootstrap 或启动模型回合。
- 额外添加员工时，首屏只需要名字。模型、项目授权、Telegram、预算和并发等设置收进「更多设置」。
- 右栏不再显示旧版「远程助理 / Chief」配置卡，只保留当前员工的档案、任务、记忆和承诺；旧配置仍用于迁移和 Telegram 兼容。
- 员工空闲时不再显示悬浮在标题中间的暂停图标；只有存在运行中、等待、任务或到期承诺时才出现，并固定在新增按钮左侧。

## 诊断报告

- Ctrl K 新增「导出诊断报告」。填写时间、步骤、预期和实际后，会生成可直接附到 GitHub Issue 的 Markdown 文件。
- 报告包含最近四代日志、UI/运行时快照和最近错误索引，不复制完整对话或项目文件。
- 自动脱敏常见 API key、Token、Authorization、URL 凭据、JWT、私钥、用户主目录和敏感 UI 字段。

## 浏览器

- 应用内浏览器现在直接支持 `file:///D:/.../index.html` 和绝对 Windows 文件路径，不再错误补成 `https://file...`。
- 开发服务器预览默认只通知，自动打开必须在 Ctrl K 显式开启；Agent 自己启动 localhost 不会再自动抢占工作区。
- Browser URL 和活动标签不再进入冷启动恢复，避免异常页面形成「启动自动恢复 → 卡死 → 强杀 → 再恢复」的循环。

## 模型与 Agent

- 修复跨用模型在 OpenCode 中缺少 `marionette/` 前缀的问题；发送前模型同步失败会明确中止，不再静默回落到 OpenRouter 默认模型继续扣费。
- 旧会话中已经保存的引擎裸模型 ID 会自动迁移为原生 wire ID。
- Grok 的 execute 模式和旧终端输出解码已对齐。

## 其它

- 修复对话滚轮向上浏览后被重新吸到底部的问题。
- 内置 magpie 继续使用已审查的 **v0.1.4406** 种子，本补丁版没有夹带新的上游引擎变更。
- 更新中英双语文案与员工模式回归：Rust `chief` 58 项、员工状态 18 项、浏览器与本地文件回归、生产前端构建均通过。

## 安装

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.7.x / 0.8.x 升级无需迁移，数据目录与配置不变。
