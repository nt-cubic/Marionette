# Marionette v0.9.0

## AI 自主派活：从能跑到能管

主对话现在可以把一项完整工作派给另一名 AI，并在不离开当前对话的情况下查看、追问、打断和收结果。派活不再要求调用方预先查完 agent 与模型清单，只给目标就能启动，执行者、模型和档位都有明确默认值。

- 子任务可以跨 Claude、Codex、OpenCode、Pi、Grok、ZCode、DeepSeek 与 Antigravity 等已接入 agent 运行。跨用模型会先建立引擎绑定，再启动 ACP，不再靠模型名字猜来源。
- 主对话可以实时读取子任务最近的活动，给正在工作的子任务补充要求，单独打断当前回合，或彻底停止任务。
- 父对话派完就结束当前回合，子任务完成后再由宿主唤醒。任务账本、等待中的回执和结果都能跨重启恢复，重复读取状态也不会再生成第二份回执。
- 子任务权限只能等于或小于父对话。只读父对话只能派出只读 worker，免审批父对话才能派出同级 worker，派出去的 worker 不能再继续派活。
- 额度或限流导致中断时，任务会按 5 / 15 / 30 分钟退避重试。连续 20 分钟没有任何进展的任务会明确记为卡死，任务结束后对应 agent 进程会收掉。
- 支持交付模板。worker 必须按指定的 JSON Schema 提交结果，缺字段或类型不符会退回重交。
- Git 项目里的子任务开工前会记录存档点，结果卡可以回滚该任务改动过的已跟踪文件。

### 派活界面

- worker 会话不再挤进项目侧栏、贴边进行中列表和命令面板。父任务卡、右栏独立的「子代理」区和父会话面包屑仍然可以打开它。
- 运行中的子代理先显示为紧凑任务行，展开后才显示实时流、插话、中断、停止和打开 worker。
- 任务卡和回复卡统一显示来源、模型与档位，例如：

```text
antigravity · OpenCode Go/DeepSeek V4.1 Flash [Max] · 22s
Full access   OpenCode Go/DeepSeek V4.1 Flash   Max
```

- `source-*` 来源会从模型来源记录中精确解析，同一模型 ID 如果经不同来源提供，会显示各自的来源名。旧对话也会根据 `modelId` 和当前来源表实时补全。

## Agent 路由与可靠性

- 共享模型选择不会再悄悄退回 agent 自己的默认模型。
- Codex 会等待本地引擎就绪再发起请求，引擎未就绪时直接失败，避免把请求送给错误端点。
- OpenCode、Pi 与 ZCode 会等待目标模型出现在实时目录或最近一次有效目录后再绑定。
- Antigravity 网关补齐 Code Assist 对话、工具调用、档位与流式响应处理，并保留本机登录状态和额度读取。
- 新增 `Marionette.exe --doctor` 与可双击的 `tools\doctor.bat`。健康检查不会开窗口、抢实例锁、唤醒引擎或读取令牌，能检查桥接绑定、失效模型选择与运行环境。

## 已知限制

- 多个派活 worker 目前仍在父会话的同一个项目工作区里运行。并发修改同一文件可能互相覆盖，发生冲突时需要人工处理。下一阶段会优先评估每个任务独立 git worktree、任务完成后清理，以及基于任务工作区的 diff 审核。
- 不同 agent 对档位、工具调用和流式事件的实现存在差异。遇到无法复现的 agent 协议问题，请用 Ctrl K →「导出诊断报告」附日志反馈。
- 回滚只处理任务期间改动过的已跟踪文件，不删除任务中新建的未跟踪文件。
- 跨机器、手机端和自动合并冲突仍不在本版本范围。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限。之后的应用内更新会原地替换程序，从 0.8.x 升级无需迁移用户数据。
