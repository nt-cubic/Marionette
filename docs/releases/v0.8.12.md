# Marionette v0.8.12

## 额度

- 修复同一个套餐显示成好几个圈：同一把 Key 被登记成多个来源时（例如 OpenCode Go 与从其它 CLI 配置里发现的 opencode.ai），现在只显示一个额度圈；不同 Key 仍然分开显示。
- 修复 Claude 订阅额度不显示：通过 npm 安装的 Claude Code、安装路径含空格或中文时也能读到额度，并且在任何对话里都可见。
- 额度改为并行读取，刷新更快；Claude 响应较慢时不再拖空整个额度面板，读到的数值会在下一次刷新时补上。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.8.x 升级无需迁移用户数据。
