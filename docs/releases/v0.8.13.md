# Marionette v0.8.13

## AI 自主派活（新功能）

在任何对话里用自然语言，就能让当前这个 agent 把活派给另一个 agent，不用再自己手动 @。例如「把这个调研派给 Codex」「让 OpenCode 用免费模型把这几个文件过一遍」。

- 对方自己选执行者、模型和推理档位；你也可以点名：「用 zcode 的 GLM」「让 Grok 来做，DS 开到 MAX」。
- 派出去的活是一个完整的对话：侧栏里带「AI 派活」角标，可以点开看全过程、随时接管。
- 派完之后它可以先休息，不必反复查询进度；活干完时系统把它叫醒收结果。主对话没开着时，结果等它下次打开再送达。
- 权限跟着主对话走：主对话开了免审批，派出去的也免审批，不再逐个弹窗；主对话是只读，它也只读。它永远不会比主对话更放行。
- 随时能停：卡片上的「停止」，或右栏后台任务面板里的 ×。停掉后卡片显示「已取消」。
- 指定的模型用不了时，任务立刻失败，并告诉你那个 agent 实际能用的模型，不会偷偷换成默认（往往最贵的）那个。
- 可以要求按固定格式交结果：派活的一方附一张交付模板，对方填不对会被打回重交。
- 在 git 项目里，结果卡上有「回滚此任务」：把这个任务期间改过的文件恢复到开工时的状态（新建的文件不动）。
- 额度或限流撞墙时自动等待再试（5 / 15 / 30 分钟，最多 3 次）；连续 20 分钟没有任何动静会被判定卡死并中止。
- 需要你确认的（权限、提问）在右栏后台任务面板里置顶；其余时候不打扰。
- 不想用的话，Ctrl K 里可以一键「关闭 AI 派活工具」。

### 使用提示

- 想让它选某个 agent 自带的模型（OpenCode 的免费模型、OpenRouter 的免费模型、zcode 的 GLM……），先给那个 agent 开着一个对话：它自己的模型清单只有在运行时才读得到。查不到清单时，它会不指定模型，而不是乱猜。
- 主对话本身是「逐个询问」时，派出去的也会逐个问，这是故意的。想不弹窗，在主对话里打开免审批。
- 不是当前对话在要权限时，弹窗会写明「来自对话：…」。

### 已知限制

- 这个功能的真实流程只经过了自动化测试，还没有在真机上用真 agent 完整跑过。Grok 的免审批、各家 agent 的模型清单和档位、停止按钮，遇到不对的地方请用 Ctrl K →「导出诊断报告」把日志发回来。
- 派活能力通过本地工具通道提供给 agent，不支持这个通道的 agent 暂时用不了。
- 「连续 20 分钟没有动静判卡死」是经验值：一条命令真的要跑 20 分钟以上，会被误判中止。
- Marionette 自己的浏览器控制、电脑控制不跟着放行，照常出确认。
- 推理档位是尽力而为：某个模型不支持档位时任务照跑，右栏后台任务面板里会写明「档位没生效，用的是默认档」。

## 额度

- 修复 Claude 订阅额度不显示：新版 Claude Code 适配器（0.109.x）把已用百分比挪进了新的字段，Marionette 现在按新字段读取，新旧两种格式都认。
- 修复 OpenCode Go 的额度行悄悄消失：两个来源共用同一个套餐位时，现在优先用名字完全匹配的那个，避免登记了没有 Go 订阅的 Key 而被拒绝。

## 模型与来源

- Claude、Codex、Grok、Gemini 这几类订阅来源，默认不再共享给其它 agent 使用；按量付费的来源（如 DeepSeek）不受影响。需要共享时，在「模型与来源」面板的「订阅共享」里逐个开启，开启前会提示账号与条款风险。
- 修复通过 npm 安装的 Claude Code 被误报「找不到 Claude」：安装路径含空格或中文时也能正确找到并启动。
- 安全加固：本地引擎网关的每次请求都要携带本机令牌；模型名会先做字符检查，再进入命令行。

## Telegram

- 推送现在带图：对话里这条回复能看到的图（截图、读到的图片、工具产出的图片、Markdown 里的图片）会随回复一起发到手机。你自己刚发给 agent 的图不会被原样推回来。每条回复最多 4 张，单张不超过 10MB。
- 图片跟随「推送带回复内容」这个开关：关掉它，正文和图片都不出本机。
- 真实 Telegram 机器人的发图流程还没有端到端验证过；发送失败只会在日志里记一笔，不影响正文。

## 用量

- 极快的回合不再被记成 0 毫秒。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.8.x 升级无需迁移用户数据。
