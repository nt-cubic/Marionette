# Marionette v0.8.14

## 模型设置（一个入口管全部）

- 原来的「模型与来源」和「API 与登录凭证」合成一个「模型设置」：左列是订阅共享四族 + 你的来源，右列是选中项的详情。左下角模型共享弹层、模型选择菜单底部、Ctrl K 都进入同一个对话框。
- 订阅共享四行可以点开：看登录状态、剩余额度、这一族里到底有什么模型（带上下文和视觉标记），共享开关就在右上角；没登录的直接点「登录」，在它自己的窗口里完成 Claude / ChatGPT / Grok / Antigravity 的登录，回来自动刷新。
- 同一厂商不再重复出现：引擎里同一把钥匙、同一厂商主机被登记成多个来源时只显示一行；同一厂商来自多个 agent 目录（例如两处 xAI）也会合成一行，点开按来源分段，显示开关和排序仍分别生效。
- 来源详情写「发现自」（本机凭据 / 哪个 agent 的配置），去掉了「借给某个 agent」——共享引擎一开，所有 agent 都能用。
- 跨用桥注入给 Grok 的模型不再当成「凭据」列出来；API Key 的检测、编辑、删除都在来源详情里。
- 视觉整理：对话框头部灰底、选中行有明确的左边条、注入徽章改成小圆点、额度窗口名不再被截断、空态直接告诉你下一步点哪里。

## 首次使用引导

- 第一次打开（还没有任何对话）会出现一页「开始使用」：自动检测本机已登录的订阅、已有的 API 来源、已启用的 agent；有什么就直接「开始第一场对话」，什么都没有才给三条路（登录订阅 / 添加 API Key 或自定义来源 / 先直接看看）。
- 不拦路，跳过就进主界面；Ctrl K 里前两项固定是「开始使用」和「模型设置」。

## 模型共享引擎

- Gemini 订阅（Google Antigravity）现在真的能共享了：内置引擎按 Antigravity 的 Code Assist 协议对话与读取模型清单，同一模型的各思考档位在目录里折成一个模型（下拉里选 low / medium / high），不再只是一个空开关。
- 联网走代理时 SOCKS 也能用（之前只认 HTTP 代理，SOCKS 会直接失败）；代理测试失败不再显示成绿色。
- 自定义来源可以填地址、协议、Key，保存前先「获取模型」看到服务端目录；保存后是动态目录，服务端新增模型自动出现；已有的自定义来源可以在列表里编辑，不必再改 JSON；手动填过模型 ID 的来源保持固定清单。
- 额度、余额和登录状态都按本机真实情况显示（之前只有 ChatGPT 会被认出来）。

## 已知限制

- Gemini 订阅的对话桥只在本机登录的 Antigravity 账号上验证过只读的模型清单；真对话会消耗这份订阅的额度，开启共享前请自行确认。
- 思考档位、工具调用按 Antigravity 的协议尽力翻译；与厂商自身应用的差异以实测为准。
- Windows 上需要 WebView2 Runtime（随 Windows 11 预装，Windows 10 可能需要单独安装）。

## 安装

下载 `Marionette.exe` 双击运行。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```
