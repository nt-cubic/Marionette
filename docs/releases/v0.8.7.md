# Marionette v0.8.7

## 浏览器与本地开发

- 本地开发页打开前会绕过 HTTP 缓存，避免脚本更新后混用旧模块；公网页面照常缓存。

## Agent 与额度

- 修复 Antigravity 运行中插话时，新消息可能被尚未结束的取消流程一起吞掉的问题。界面仍会立即停止当前输出，但排队消息会等 Agent 真正确认取消后再发送；长时间无确认时会自动重启并重放对话。
- Antigravity 的 `/usage` 额度已接入右栏，刷新或回合结束后可显示 Gemini、Claude/GPT 等额度组、剩余比例和重置时间。

## 图片附件

- 图片附件弹窗默认进入可裁剪状态，四边和四角均可拖动；保存时生成新的裁剪图片，原图不变，已有批注会随裁剪重新映射。
- 未发送的图片附件现在按会话保留。切换对话、分屏焦点或切换 Agent 后再回来，图片、裁剪结果和批注仍在；发送或手动移除后才清空。

## 轨迹视图

- 轨迹图新增「通讯」泳道，显示从消息发出到首个活动、以及工具回传后到下一次模型响应之间的等待时间。
- 通讯时间按实际 wire 发送和结束边界计算，排除 100ms 以下的调度噪声；它是请求等待观测，不等同于 ping 或单独的 TCP 握手耗时。

## 浏览器与窗口

- 对话中的网页链接继续优先在应用内浏览器打开，并保持当前分屏位置；没有本地浏览器宿主时回退到系统浏览器。
- 修复内置浏览器子视图覆盖应用浮层的问题，图片预览、权限确认和其它弹窗可正常显示在网页上方。

## 标签与滚动

- 多图会话切换标签后会回到离开时正在看的位置；图片稍后加载导致卡片高度变化时，视图不再漂移。手动滚动或点击后会立即停止自动校正。

## 安装

下载 `Marionette.exe` 双击运行，需要 WebView2 Runtime。也可以在 PowerShell 中运行：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```

安装器会装进开始菜单并加入用户 PATH，不需要管理员权限；之后的应用内更新会原地替换程序。从 0.8.x 升级无需迁移用户数据。
