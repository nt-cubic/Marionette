# Marionette v0.9.1

## 模型共享和多 Agent 可靠性

此更新修复了派发子任务时的模型来源别名解析。DeepSeek Harness 启动现在更加可靠，并且子代理列表具有最大高度。

- 稳定来源别名（例如 `opencode-go/deepseek-v4.1-flash` 和 `ollama/deepseek-v4.1-flash`）现在自动解析为引擎当前公布的动态 `source-*` 模型 ID。用户不再需要输入随时间变化的内部 ID。
- 当引擎刚刚启动且实时模型发现尚未跟上时，DeepSeek Harness 使用最近一次有效模型目录。它仍然为当前模型传入会话级 `--bundle`，并且不会回退到过时的 ambient 路由。
- 在列表内滚动之前，右侧边栏中的子代理列表显示大约 8 行。更多任务仍可在该区域滚动查看。配额和更改文件信息不再无限期地向下推送。

## 验证

- OpenCode、Codex CLI、Claude Code、Grok Build、Pi、DeepSeek Harness、ZCode 和 Antigravity 都通过 DeepSeek V4.1 Flash 的 OpenCode Go 和 Ollama 路由完成了真实派活。
- 0.9.1 版本上的 OpenCode 和 DeepSeek Harness 快速验证均返回了预期结果。
- TypeScript 检查、派活回归测试、前端生产构建、Rust 桥接测试和 `cargo check` 全部通过。

## 安装

下载并运行 `Marionette.exe`。需要 WebView2 运行时。您还可以从 PowerShell 安装：

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```
