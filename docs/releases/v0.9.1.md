# Marionette v0.9.1

## Model sharing and multi-agent reliability

This patch resolves model source aliases during delegation, hardens DeepSeek Harness startup, and keeps a busy subagent list from crowding the right rail.

- Stable provider aliases such as `opencode-go/deepseek-v4.1-flash` and `ollama/deepseek-v4.1-flash` now resolve to the current dynamic `source-*` catalogue route.
- DeepSeek Harness now uses the last good model catalogue while live discovery catches up after engine startup. Workers no longer skip their per-session `--bundle` and fall back to a stale ambient route.
- The Subagents section now shows about eight rows before scrolling internally, leaving room for quota and changed-file details.

## Validation

- OpenCode, Codex CLI, Claude Code, Grok Build, Pi, DeepSeek Harness, ZCode, and Antigravity passed real delegation tests with both the OpenCode Go and Ollama routes for DeepSeek V4.1 Flash.
- Each ACP harness completed a real first turn and returned the expected marker.
- TypeScript checks, delegation regressions, the production frontend build, Rust bridge tests, and `cargo check` passed.

## Install

Download and run `Marionette.exe`. WebView2 Runtime is required. You can also install from PowerShell:

```powershell
irm https://github.com/nt-cubic/Marionette/releases/latest/download/install.ps1 | iex
```
