# 域开发手册模板（写手册前先读我，写完删掉本行以上不需要的说明）

> 这是 `docs/manual/<域>.md` 的固定骨架。目标读者：**未来改这块代码的人（或代理）**。
> 手册回答四件事：这块是什么 / 改什么去哪找 / 哪些事绝不能做 / 搞定后测什么。
> **不复制行为描述**（产品行为在 `docs/CURRENT.md`）；**不复制实现细节**（真相在各模块头注与代码）——手册是索引 + 红线 + 检查单。
