停靠是主窗本身变窄变高，不是第二个窗口：开着的对话、草稿、进行中的回合原地保留。下面六屏：收起、展开，以及收纳盒的浏览、多选、整理成文档、用选中的开新对话。第一屏可以把鼠标移到右边那条 4px 上，看它滑出来（约 160ms，9 步，和计划里的整窗 set_position 步进一致）。

① 收起（docked-hidden）

只剩 4px 高亮边。后台完成的任务在边上挂一个计数，同时走现有桌面通知；不抢焦点。

② 展开（docked-expanded）

自上而下：操作行 → 余额 → 工程对话 → 开着的对话和输入框 → 模型共享与设置。离开 300ms 且失焦后收回。

③ 收纳盒 · 浏览

链接、文字、图片、文件都往里扔。按类型筛、按标题 / 内容 / 标签搜；标签由「模型共享」里最便宜的模型自动打，可改可删。

④ 收纳盒 · 多选

点「选择」进入多选；底部浮出选择栏：已选数、整理成文档、开新对话。点行就勾选，Esc 或 × 退出。

⑤ 一键整理成文档

选中的条目（或整盒）交给模型按主题归并、去重、列出待办，先出草稿；确认后存进项目的 docs/notes/，原条目留在盒里。

⑥ 用选中的开新对话

新开一个对话标签，选中的条目作为附件挂在输入框上（文件给路径、图片给图、链接给标题和网址），你补一句话就能发。

沿用的现有语言

  • 色值取自 tokens.css，3px 直角、同一组灰，青绿只表示「进行中 / 可操作」。
  • 会话行、状态过滤胶囊、活动折叠、交付卡、输入框芯片、「模型共享」入口行，都和主窗现在的组件一模一样，只是排进 360–400px。
  • 标签页和分屏：dock 态只保留横向标签，分屏禁用（计划 §3.4）。

从 Arc 借的

  • 余额 chip：同一行按「最紧张的在前」排，红色只给 ≥90%，点开就是右栏那套按来源分组的额度（Usage meter）。
  • 收起时完成的任务：边上挂计数 + 右下角结果提示（Toast stack），不弹窗、不抢焦点。
  • 收纳盒：一行一条，悬停才露操作，底部一块虚线放置区（Knowledge base 的列表 + File dropzone）。

动效约定

  • 滑出 / 收回：窗口按 9 步滑动，约 160ms；长条内部内容不再另做动画，免得整窗重绘时卡顿。
  • 收纳盒覆盖层：180ms 淡入，带一点点缩放；关闭直接消失。
  • 运行中的折叠标题用现有的文字微光；状态点用现有的脉动；系统「减少动态效果」时全部变成瞬时。
