横平竖直、克制、结论先行。界面本身是中性灰阶，只有「谁在做」用颜色说话，而且是压低饱和的墨色。
八条规则
01对话流一轮三段：你 → 调用块（轨迹、思考、工具都在块里）→ 回复。卡距 6px、圆角 3px、1px 边、无阴影。
02身份色只上三处：3px 左边条、运行中的描边与流光、当前项的进度条。名字和状态用中性色。
03控件贴着表面长，不做独立的框：搜索在标题行里，输入框是整条，表单是一行一行的表。
04结论先行：一行写结论（26% / 已满 / 4 个文件），细节点开或悬停再看。
05主数字大、名词小：数字 15–20px / 600，名词 11px 居中写在下面。
06主次靠粗细和灰度：主条 4–6px agent 色，次条 2px 浅灰；主值加粗，次值辅助灰。
07状态只写在文字上：黄 = 快满 / 等你，红 = 已满 / 出错，绿 = 增行 / 通过。不占圆点。
08动效只说明「从哪来、到哪去、谁在跑」：进出成对，只动 transform / opacity，循环只给 live 元素。
