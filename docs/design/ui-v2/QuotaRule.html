额度高亮规则
高亮的是「这一轮在花谁的钱」
01名字 = 计费来源：自家模型就是 agent 自己的订阅；经模型共享的模型，按 marionette 前缀的 id 反查到来源（DeepSeek、智谱……）。

05中途换模型：高亮块换成新的来源，竖条亮一下。同一个 agent，竖条颜色不变。
06对不上来源时（agent 自报的模型 id 查不到）：退回 agent 自家订阅，小字写「来源未知」，不猜。
